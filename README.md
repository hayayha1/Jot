# 随记

一款先记下来、稍后整理的 Windows 本地随记本。浅白色两栏界面，左边切换笔记，右边连续记录；不需要账号、云服务或手动保存。

界面参考 [FSNotes](https://github.com/glushchenko/fsnotes) 的笔记列表与编辑区。FSNotes 使用 Swift，面向 macOS/iOS；本项目为 Windows 重新实现交互和布局，没有直接搬用其原生界面代码。

## 安装与打开

双击 `release/Suiji-Setup-0.2.1.exe` 完成安装，然后在 Windows 搜索「随记」即可打开。安装程序会创建开始菜单入口，可以选择桌面快捷方式。也可直接运行 `release/win-unpacked/随记.exe`，但未安装版本不会自动加入 Windows 搜索。

本项目使用 Electron 构建，交互以轻便、快速记录为目标；运行时和安装体积仍明显大于系统记事本。发行包暂未购买代码签名证书。

## 0.2.1 版交互

- 新笔记从一行开始，通过 Enter 逐行扩展；正文超出可视区域时显示内部滚动条，只有正文随光标或滚轮移动，左侧列表、顶栏、工具栏、标题和状态栏固定。末尾空行会保存并在重启时恢复。
- 笔记正文是一个连续编辑区。直接点击原文修改，Enter 换行，Backspace/Delete 合并相邻段落，Ctrl + Z 撤销，不需要发送或另开编辑对话框。
- 页面顶栏和笔记工具栏分为上下两行。工具栏紧贴页面顶栏下沿，两行都在笔记标题上方。
- 工具栏提供图片、超链接、加粗、列表、代码、撤销/重做、命名分组和时间分组。
- 笔记内搜索平时只显示最右侧的放大镜。点击或按 Ctrl + F 展开输入框，输入后高亮并跳到匹配位置；Enter 下一处，Shift + Enter 上一处。查找保留完整正文。
- 点击笔记内搜索框，可在下拉栏选择「图片」或「超链接」，查看当前笔记中的所有对应内容，并从结果定位回原文。
- 左侧全局搜索只搜索笔记，不再带「全部/图片/链接」筛选栏。Ctrl + K 聚焦全局搜索。
- 图片和网址可直接粘贴到正文；普通单击超链接会交给系统设置的默认浏览器，无需 Ctrl。链接打开不改变笔记窗口，也不会把链接格式带到下一行。图片也支持拖入和工具栏文件选择。
- Ctrl + G 或工具栏「分组」会直接包住光标所在行；选中多行时包住所选行，保留原文字、记录 ID 和时间，不在下一行新建空块。已在分组内时直接编辑当前组名。
- 工具栏的「时间分组」开关控制时间标记；相邻段落书写间隔达到 3 分钟或跨日时显示新组。编辑旧段落会保留原创建时间。
- 输入自动保存，关闭前等待最后一次写入。旧版尚未提交的草稿会完整转入可编辑正文。
- 多笔记、重命名、置顶、归档恢复、含图片的 HTML 导出和本地 MCP 仍然可用。

## MCP 连接

在桌面版右上角点击「连接 Agent」，复制当前安装位置对应的 MCP 配置，添加到支持 MCP 的客户端后重启客户端。安装版自带运行环境，不需要额外安装 Node.js。

源代码模式可使用下面的配置，路径替换为你的项目位置。默认数据位置与桌面版一致。

```json
{
  "mcpServers": {
    "suiji": {
      "command": "node",
      "args": ["D:/projects/随记/mcp/server.mjs"]
    }
  }
}
```

可对 Agent 说：「读取日常随记，把关于项目的记录归入一个命名分组，保留原文和时间。」

可用工具：`list_notes`、`get_note`、`search_notes`、`create_note`、`append_entry`、`rename_note`、`create_group`、`move_entries`、`update_entry`。修改现有笔记需要传入刚读取的 `revision`；版本已变更时会拒绝写入，Agent 需要重新读取。Agent 不提供删除工具，含图片的记录也不能被纯文本覆写。笔记正文按用户数据处理，工具描述明确提示其不构成 Agent 指令。

## 数据与备份

桌面版笔记保存在 `%APPDATA%/Suiji/notes.json`，图片包含在文件内。设置中可直接打开数据文件夹。设置环境变量 `SUIJI_DATA_DIR` 可以指定其他位置，桌面版和 MCP 必须使用相同位置。

保存采用进程间写锁、临时文件、磁盘刷新和原子替换，避免界面与 MCP 相互覆盖。`notes.json.bak` 是上一次成功写入前的版本，不是长期版本历史。若需恢复，先关闭随记及 MCP 客户端，另存损坏文件，再把备份复制为 `notes.json`。损坏文件不会被静默重置。建议定期复制整个数据文件夹做独立备份。

正文直接保存在 `notes.json`，包括已有内容的修改。0.1 版的普通输入草稿会在打开时迁入正文。旧版独立编辑弹窗的暂存内容位于浏览器配置中，升级前请先在 0.1 版保存这些弹窗里的修改。浏览器预览使用浏览器本地存储，与桌面版数据相互独立，不支持本地 MCP。

当前版本不含多设备同步、云端服务、OCR 或语义搜索。图片筛选按内容类型识别；正文关键词查找不识别图片内文字。数据为本机明文存储，尚未加密。

## 开发

需要 Node.js 24+、Windows 10/11 x64。

```powershell
cd D:\projects\随记
npm install
npm run dev
```

项目依赖已安装的情况下，直接运行 `npm run dev` 即可打开桌面版；也可以用 `npm start` 打开已经构建好的桌面界面。`npm run dev:web` 仅用于浏览器预览，系统默认浏览器打开链接的行为以桌面版为准。

如果安装环境禁用了依赖安装脚本，需运行 `node node_modules/electron/install.js` 下载桌面运行时。

```powershell
npm run dev:web   # 浏览器预览
npm run build     # 构建界面
npm test          # 数据、并发及真实 MCP 协议测试
npm run test:ui   # 先 build，再执行真实 Electron 窗口交互测试
npm run dist      # 生成 Windows 安装包
npm run test:release # 直接验证打包版及其自带 MCP 服务
```

测试使用独立目录，不修改真实笔记。UI 测试截图在 `test-results/`。

交付验证：30 项数据、编辑命令和 MCP 测试；桌面回归覆盖 74 行连续编辑、滚轮及查找只滚动正文、默认浏览器打开调用、原地分组、末尾空行恢复，以及既有的图片、搜索、撤销和 Agent 同步流程。安装包约 108 MB，应用自身资源约 1.5 MB，其余主要为桌面运行时。

前端采用 React + Tiptap，桌面壳采用 Electron，MCP 采用官方 TypeScript SDK。界面不加载远程字体、图片或脚本；笔记链接由系统浏览器打开，渲染进程不暴露 Node.js。
